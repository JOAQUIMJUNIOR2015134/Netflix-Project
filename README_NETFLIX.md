# 🎬 Netflix Clone

Um clone da Netflix desenvolvido com React + Vite, utilizando a API do The Movie Database (TMDB) para exibir filmes e séries.

## 🚀 Funcionalidades

- 📱 Interface responsiva inspirada na Netflix
- 🎯 Navegação entre filmes e séries
- 🔍 Barra de pesquisa funcional
- 📄 Páginas de detalhes para filmes e séries
- 👥 Exibição de elenco e equipe técnica
- 🎭 Seções: Popular, Top Rated, Now Playing, Upcoming
- 🔗 Sugestões de conteúdo relacionado

## 🛠️ Tecnologias Utilizadas

- **React** - Biblioteca JavaScript para interfaces
- **Vite** - Ferramenta de build rápida
- **React Router** - Navegação entre páginas
- **CSS3** - Estilização
- **TMDB API** - Dados de filmes e séries
